# Glass B, the product: the phone's bottom chrome on one glass

Real emulator screenshots (API 35, sdk_gphone64_x86_64, 1080x2400 at 420 dpi, three-button navigation, the debug build), the system's animations on (with them removed the app draws the glass opaque). "0-first-frames": read as soon as the window of a cold start into the page had drawn; "1-cold-start": that page settled; "2-player": the page again with a track paused in the mini player; "3-moved": its list moved under the bars. The walk read the bar's and the card's glass on each (the run's checks): it blurs, nothing sharp beneath it.
