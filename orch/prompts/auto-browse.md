## 1. Why Auto shows only search (the orchestrator's finding — verify it, then fix it)
`app.nagmedar.ui.auto.CarIds.ROOT` is `const val ROOT = MediaSessionBrowser.ID_ROOT`, and `MediaSessionBrowser.ID_ROOT` (vlc-android) is `const val "//${BuildConfig.APP_ID}/r"`: a compile-time constant that differs per build type. `nagmedar-ui` has no `personal` (nor `benchmark`) build type, so the app's personal build takes nagmedar-ui's `release` variant, compiled against vlc-android's `release` (APP_ID `app.nagmedar`): its CarIds are inlined as `//app.nagmedar/r/…`, while the running service is vlc-android's `personal` (APP_ID `app.nagmedar.debug`) and hands Auto the root `//app.nagmedar.debug/r`. `CarTree.children` → `CarIds.parse` rejects that root → `MediaSessionBrowser.browse` returns an empty list → Auto has no tabs, only its search (search works: its ids come from CarIds on both ends). Debug builds are consistent, which is why the walk and the unit tests never saw it. Also check `MediaSessionBrowser.isNoMedia` / `CarIds.NOTHING` and `notifyChildrenChanged` ids for the same split.
- Make no Auto id depend on the build type (e.g. a fixed root in MediaSessionBrowser, or ids read at run time), and grep every module for other `const val`s built from a build-type BuildConfig field that a module without that build type inlines. Do not invalidate anything persisted (Media3/Auto resumption stores the last media id: an id from 1.0.2 that no longer parses must play nothing quietly, never crash).
- A regression check on the **personal (R8) build**, end to end: something that connects a `MediaBrowserCompat` to `app.nagmedar.debug`'s `org.videolan.vlc.PlaybackService` (exported), loads the root and every tab and asserts what a car would get: four tabs, the Music tab's lists filled from the walk's 64 "Profile track" files, Podcasts with the walk's feed, Radio's lists (offline: the one "cannot reach" line). The cheapest place is probably an instrumented test in `application/benchmark` (it is built for the emulator already) run by `buildsystem/ci/emulator_smoke.py` with `am instrument`, as one short step of the personal walk; keep it under a minute.

Playing a directory station counts the click as the app does; offer "Favorilere ekle" as a custom action where supported.
- Search stays grouped (music, followed podcasts, new podcasts from the directory, radio) and voice keeps working.
- Respect Auto's limits (page long lists, few levels, artwork through CoverHook/ArtworkProvider, every list's empty and offline line in Turkish and English). Every user-visible string in both locales per TERIMLER.md.
