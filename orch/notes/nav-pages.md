## 1.0.1 nav-pages (PR #90, branch story/nav-pages): NOTES FOR THE NEXT STORY

- Navigation: `shell/ShellNavigator.kt`. `NavRules` (pure, tested in NavRulesTest): `tabs(kind)` (phone Müzik·Podcast·Radyo·⋯; rail + More, Settings; sidebar = Destination.sidebar), `tabOf/highlighted` (the tab whose stack holds the page, probed with `inStack`; Search lights none), `moveFor` (Tab/Reselect/Open), `showsBack` (phone+rail, non-tab pages), `fullPages`/`hidesBars` (phone: Settings, About, Guide, ShortcutCard, AllSettings have no bottom bar / mini player), `backToStart`.
- `ShellNavigator`: `selectTab` (chrome; reselect pops to the tab root), `open` (pushes on the current tab's stack; a page already in the stack is popped back to), `navigate` (= by the window: tab or open; use it when the caller does not know), `back()` (another tab's root → Müzik; false at Müzik's root), `lastMove` drives the shell's transitions (Open → page slide, pops slide back unless Reselect). `navKind` is written by the shell during composition. One navigator instance: NagmedarApp passes its own to `NagmedarShell(navigator = …)`.
- Back from another tab's root is a `BackHandler` composed first inside each NavHost entry (screen handlers win; disabled while the phone's player is expanded, whose handler is older). Back arrow = `onBackPressedDispatcher.onBackPressed()` (a page's detail closes first, like the key).
- Bars: `PageTopBar(onBack)` solid `colors.background`, title/arrow fade through (`NagMotion.topBarChange`). Bottom bar / mini player card / floating player are plain solid backgrounds. The shell's `glass` default is now false (GlassMode.Solid); Glass.kt untouched. `ShellScrollState.scrolled` removed (`onScrolled(consumedY)`).
- Full pages: `ShellChromeMetrics.barsHidden`, `bottomPadPx(bars)`; each entry's `ShellScreenFrame(bars = …)` provides its own `LocalShellContentPadding`; the bars slide out by `bottomOffset` and are clipped at the window edge (`ShellLayout.slideDown`). Frames draw an opaque background (pages slide over each other).
- Motion: `NagMotion.pageEnter/pageExit/pagePopEnter/pagePopExit` (end-edge slide, 25 % parallax, phone spring), `dialogEnter` + `DIALOG_SCALE`. `NagDialog` sets no window animation (`StillDialogWindow`) and scales the card; raw `Dialog(`s in Downloads/RemoteAccess/Streams are NagDialog now. Menus check `shellOverlayHere()` before using glass.
- More page: `screens/Common.kt` `MoreScreen(destinations, onSelect, actions: List<MoreActionGroup>)`, testTag "more-page".
- Tests: TestShell takes `moreActions: List<MoreActionGroup>`, reaches a start page through `wayTo(destination, kind)` (as a person would: ⋯ then the page, Settings then About); `PhoneNavigationTest` drives the phone shell. Walk: `phone_pages()`, `top_bar_colour_check()`, `has_bottom_bar()` in emulator_smoke.py.
