# story/crash-sweep (1.0.1, PR #88) — notes for the next story of this track

- F1 root cause: `DenseTable` passed caller keys straight to `LazyColumn.itemsIndexed(key=…)`; `DeviceScreen` keyed by `DeviceLocation` (plain data class) → "Type of the key Path(...) is not supported" as soon as a folder's first row composed. Red proof: CI of dc2c82df (scratch agents/crash-sweep/red-run-dc2c82df.txt).
- `components/DenseTable.kt` `lazyKeys(keys: List<Any>): List<Any>` (internal): Bundle-safe keys (String, boxed primitives, Char, Boolean, Enum, Parcelable) stay; others become "\u0001"+toString; repeats become "\u0002<n>\u0002"+key. Use it for any lazy list whose data may repeat or whose keys are not Bundle-safe: `val keys = lazyKeys(list.map { … }); itemsIndexed(list, key = { i, _ -> keys[i] })` (done in Search's sections and Radio's StationList). DenseTable's selection still compares caller keys; reorder handles get the list keys (ReorderState compares against `visibleItemsInfo.key`).
- `DeviceLocation.uri` is the device table's row key and selection key; it never throws (bad tree → "$tree#$id").
- `DeviceScreen(prefs, source: DeviceSource? = null)`: tests pass a fake `DeviceSource` (see device/DeviceScreenTest.kt `SampleDevice`).
- Queue keys: `playback/PlayQueue.kt` `rekeyed()` re-derives "$location#$time" keys; use it whenever entries are spliced locally (restore did; move only permutes).
- Podcast search: Podcast Index answers go through `PodcastSearch.merge` too (duplicates by feed). Palette: `paletteResults` dedupes items by id and recent ids.
- SafLibrary: a provider failing mid-read is caught per folder (`readFolder`); results are cached per tree (`SafLibrary.forget`).
- Checked safe (do not redo): all rememberSaveable/Savers, all `!!`, first()/last(), computed coerceIn ranges (split panes/inspector/panes), comparators, other lazy keys (DB ids, groupBy keys, distinct lists).
- Emulator walk: `device_walk(wide)` in buildsystem/ci/emulator_smoke.py (phone-en after phone_player, phone-tr after phone_sheets, workstation at its end); helpers `in_tag(nodes, tag, text)`, `tap_until`, `device_playing` (mini-player or the tablet's transport-bar title). `gone_words` ignores text inside device-table/device-trail (Android's own "Movies" folder). The walk takes ~42–45 min of the 50 min deadline: keep new steps few.
- Evidence branches are shared with other agents: fetch with `git fetch origin +refs/heads/ci/emulator:refs/remotes/origin/ci/emulator` (the worktree's refspec covers only master and story/*) and check the commit subject's sha.
