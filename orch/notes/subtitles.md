## NOTES FOR THE NEXT STORY (subtitles: whisper speed, GPU through Vulkan; PR #57, branch story/whisper-speed)

- Where whisper runs: native/lab/whisper_engine.cpp (whisper_engine_threads / _open / _fall_back / _close / _json), used by whisper_subs.cpp and whisper_lab.cpp. GPU = ggml's Vulkan backend, Android build only (NAGMEDAR_VULKAN in native/lab/CMakeLists.txt); the host build is CPU-only and test-host.sh's smoke test reports fallback "none".
- No DT_NEEDED libvulkan: native/lab/vulkan_loader.c defines the 4 vk* functions ggml calls by name (vkGetInstanceProcAddr, vkGetDeviceProcAddr, vkGetPhysicalDeviceFeatures2, vkCmdCopyBuffer) and dlopens the loader on the first GPU ask (Vulkan 1.2 required). A ggml bump may add direct vk* calls: `nm -u libggml-vulkan.a | grep " vk"` and add shims, or the arm64 link fails (--no-undefined).
- `-Wl,--wrap=ggml_backend_vk_reg`: the registry's auto-registration returns null until whisper_engine registers Vulkan itself (so CPU-only jobs never open libvulkan). Verified with GNU ld and lld.
- Build: versions.env pins Vulkan-Headers/SPIRV-Headers/glslang/SPIRV-Tools at vulkan-sdk-1.4.363.0 and shaderc v2026.4; build.sh builds glslc into native/.work/tools (CI cache "Önbellek · glslc", key = versions.env hash). Ubuntu's glslc lacks GL_EXT_integer_dot_product. The lab .so grows ~45 MB (SPIR-V); coopmat2/bf16/fp4/fp8 shaders (~5 MB) are useless on Android and could be dropped by patching ggml-vulkan's CMake feature tests.
- Kotlin: WhisperAcceleration (Auto/CpuOnly, prefs key nagmedar_whisper_acceleration), crash guard WhisperPrefs.gpuRunning/gpuStopped (commit(), left out of backups) checked inside WhisperWorker's nativeLock; NativeLab.Transcription.onEngine(gpu, device, threads); WhisperEngine (WhisperJobs.kt) rides in progress/output Data; WhisperWorker.engineLine() formats "GPU · Vulkan · gerçek zamanın N katı".
