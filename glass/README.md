# Glass decision: the phone's chrome in three modes

Real emulator screenshots (API 35, sdk_gphone64_x86_64, 1080x2400 at 420 dpi, three-button navigation, the debug build), switched with the debug-only extra `app.nagmedar.debug.CHROME_GLASS`. A = all opaque (the product today); B = the mini player, the bottom bar and the band behind the buttons on one glass, the top bar opaque and never changing colour; C = the kit's: B and a top bar that fades to glass while content passes under it. The track is paused. On the Music and Playlists pages the page's own header stays under the top bar (only the search page's list scrolls beneath it on a phone), so C's top bar shows its glass over that header there.
